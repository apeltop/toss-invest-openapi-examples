# 토스증권 Open API 강의 예제

토스증권 Open API 활용 강의의 코드와 실행 방법을 모아 두는 저장소입니다. 각 폴더는 독립적으로 복사해 실행하거나, 강의 내용을 복습할 때 참조할 수 있습니다.

## 강의 목록

| 강의 | 주제 | 폴더 |
| --- | --- | --- |
| 2강 | 토스증권 Open API OAuth2 액세스 토큰 발급 | [lessons/02-toss-invest-oauth-token](lessons/02-toss-invest-oauth-token) |

## 강의 폴더 규칙

- 강의 자료는 lessons/NN-주제 형식의 폴더에 추가합니다.
- 각 강의 폴더에는 실행 방법을 설명하는 README.md를 둡니다.
- 인증 정보가 필요한 예제는 .env.example만 올리고, 실제 .env와 토큰은 올리지 않습니다.
